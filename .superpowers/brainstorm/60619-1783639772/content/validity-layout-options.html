Study 1 target-validity figure: choose the evidence structure

Nature/Science-style, 183 mm double-column canvas. Mock values reflect the current four-subject production pilot only; final code will render the complete cohort.

A · Evidence ladder (recommended)

First show the biologically interpretable dose–response, then summarize convergent validity and reliability as estimates with uncertainty. Strong narrative flow; no dashboard styling.

B · Target-by-target columns

Easy to compare all evidence within each signature. More repetition, and categorical verdict boxes can overstate what continuous diagnostics establish.

C · Compact validity matrix

Most space-efficient and useful as an overview. It hides distributions, encourages colour-based magnitude reading, and mixes construct evidence with technical QC.

Recommendation: A. It aligns each panel with a distinct scientific question and keeps technical validity in a separate Supplementary Figure S2.
